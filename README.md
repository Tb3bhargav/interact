# Sanskrit Heritage

A vibrant, dependency-free WebGL destination hero for Kashi, Ujjain, and Nalanda.

## Run locally

```powershell
npm start
```

Open `http://127.0.0.1:8000`.

## Included

- Three.js fragment-shader liquid curtain transitions
- GSAP timeline-driven destination changes
- Devanagari-first typography
- Responsive editorial museum interface
- Pointer-reactive WebGL parallax
- Drag/swipe travel and left/right arrow-key navigation
- Journey-index menu with direct destination selection
- Accessible destination tabs and controls
